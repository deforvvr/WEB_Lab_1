# Скрипты для управления проектом

## Основные скрипты

### ЗАПУСК.bat
**Главный скрипт для запуска сервера разработки**
- Проверяет наличие Python
- Проверяет и устанавливает зависимости (если нужно)
- Применяет миграции базы данных
- Запускает Django сервер

**Использование:** Просто запустите этот файл для запуска проекта.

---

### НАСТРОЙКА_ПРОЕКТА.bat
**Полная настройка проекта (выполняется один раз при первом запуске)**
- Устанавливает все зависимости
- Удаляет старую базу данных
- Создает миграции
- Применяет миграции
- Создает новую базу данных

**Использование:** Запустите этот файл один раз при первом запуске проекта из папки `scripts`.

---

### ПРОСТОЕ_РЕШЕНИЕ.bat
**Исправление ошибок базы данных**
- Удаляет старую базу данных
- Создает новые миграции
- Применяет миграции

**Использование:** Запустите этот файл из папки `scripts`, если возникают ошибки типа "no such table".

---

### ПРОВЕРКА.bat
**Проверка структуры проекта и зависимостей**
- Проверяет наличие Python
- Проверяет установленные зависимости
- Проверяет структуру папок
- Проверяет наличие базы данных

**Использование:** Запустите из папки `scripts` для диагностики проблем.

---

### ОЧИСТКА.bat
**Очистка временных файлов**
- Удаляет файлы __pycache__
- Удаляет .pyc файлы

**Использование:** Запустите из папки `scripts` для очистки временных файлов (база данных и медиафайлы не удаляются).

---

## Порядок использования

### Первый запуск проекта:
1. Перейдите в папку `scripts` и запустите `НАСТРОЙКА_ПРОЕКТА.bat`
2. Создайте администратора: `python manage.py createsuperuser`
3. Запустите `ЗАПУСК.bat` из папки `scripts`

### Обычный запуск:
1. Перейдите в папку `scripts` и запустите `ЗАПУСК.bat`

### Если возникли ошибки с базой данных:
1. Остановите сервер (Ctrl+C)
2. Запустите `ПРОСТОЕ_РЕШЕНИЕ.bat` из папки `scripts`
3. Запустите `ЗАПУСК.bat` снова

**Примечание:** Все скрипты автоматически переходят в корень проекта, поэтому их можно запускать из любого места.
