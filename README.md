# Театральная студия «В Созвездиях» - Django Backend

Проект представляет собой веб-приложение для театральной студии с полным функционалом бэкенда на Django.

## Возможности

- ✅ Регистрация и авторизация пользователей с хешированием паролей
- ✅ Строгая валидация паролей согласно требованиям
- ✅ Личный кабинет с отображением данных пользователя
- ✅ Система отзывов (создание и отображение)
- ✅ Каталог товаров/услуг с категориями и ценами
- ✅ Корзина покупок (добавление и удаление товаров)
- ✅ Форма обратной связи
- ✅ Авторизация через сессии (куки)

## Требования к паролю

Пароль должен соответствовать следующим требованиям:
- Не менее 8 символов
- Не более 128 символов
- Как минимум одна заглавная и одна строчная буква (латиница или кириллица)
- Как минимум одна цифра (только арабские цифры 0-9)
- Специальный символ (!@#$%^&*()_+-=[]{};':"|,.<>/?)
- Без пробелов
- Только латинские или кириллические буквы

## Установка и запуск

### Быстрый запуск (рекомендуется)

1. **Первый запуск:**
   - Запустите `scripts\НАСТРОЙКА_ПРОЕКТА.bat`
   - Создайте администратора: `python manage.py createsuperuser`
   - Запустите `scripts\ЗАПУСК.bat`

2. **Обычный запуск:**
   - Запустите `scripts\ЗАПУСК.bat` из папки `scripts` или из корня проекта
   - Откройте браузер: http://127.0.0.1:8000/

### Ручная установка

1. Убедитесь, что у вас установлен Python 3.8 или выше

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Примените миграции:
```bash
python manage.py makemigrations
python manage.py migrate
```

4. Создайте суперпользователя (для доступа к админ-панели):
```bash
python manage.py createsuperuser
```

5. Запустите сервер разработки:
```bash
python manage.py runserver
```

6. Откройте браузер и перейдите по адресу: http://127.0.0.1:8000/

7. Админ-панель доступна по адресу: http://127.0.0.1:8000/admin/

### Скрипты управления

Все скрипты находятся в папке `scripts/` (можно запускать из любого места):
- `ЗАПУСК.bat` - запуск сервера разработки
- `НАСТРОЙКА_ПРОЕКТА.bat` - первоначальная настройка проекта
- `ПРОСТОЕ_РЕШЕНИЕ.bat` - исправление ошибок базы данных
- `ПРОВЕРКА.bat` - проверка структуры проекта и зависимостей
- `ОЧИСТКА.bat` - очистка временных файлов (кэш Python)

Подробное описание каждого скрипта см. `scripts/README.md`

## Модели данных

- **User** - Кастомная модель пользователя с полями: username, email, phone, password
- **Category** - Категории товаров/услуг
- **Product** - Товары/услуги с ценами
- **Review** - Отзывы пользователей
- **CartItem** - Элементы корзины покупок
- **ContactMessage** - Сообщения из формы обратной связи

## Основные URL маршруты

- `/` - Главная страница
- `/register/` - Регистрация
- `/login/` - Вход
- `/logout/` - Выход
- `/profile/` - Личный кабинет
- `/katalog/` - Каталог товаров
- `/kontakts/` - Контакты
- `/about/` - О нас
- `/privacy/` - Политика конфиденциальности
- `/admin/` - Админ-панель

## Использование

1. Зарегистрируйтесь на сайте через форму регистрации
2. Войдите в систему используя логин и пароль
3. Просматривайте каталог товаров/услуг
4. Добавляйте товары в корзину (требуется авторизация)
5. Управляйте корзиной в личном кабинете
6. Оставляйте отзывы на главной странице
7. Используйте форму обратной связи для связи с администрацией

## Заполнение базы данных

Для добавления категорий и товаров используйте админ-панель Django:
1. Войдите в админ-панель по адресу `/admin/`
2. Создайте категории товаров
3. Добавьте товары с указанием категории и цены
4. Загрузите изображения для товаров (опционально)

## Технологии

- Django 4.2+
- Python 3.8+
- SQLite (база данных по умолчанию)

## Примечания

- Все пароли хранятся в захешированном виде
- Авторизация использует Django sessions (куки)
- Статические файлы автоматически обслуживаются в режиме разработки
- Для продакшена необходимо настроить сбор статических файлов
